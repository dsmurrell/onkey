# OnKey glossary

Pasted into every translation request, and read by reviewers. Each language's own renderings are in
`style/<lang>.md` under "Terms"; this file says what each term *means* and how to treat it everywhere.

**Treatment:** **keep** = write exactly as in English, in Latin letters, in every language.
**translate** = use the natural word in the language (see the style guide's table).
**system** = use the exact label the operating system shows in that language, or the text will point at
something the user can't find.

## Voice
The English is British ("licences", "favourite"). OnKey talks like a friend who knows music: plain, warm, short.
Everyday words, short sentences, "you", no jargon, no hype, few exclamation marks. Real examples:
- "Learn to sing the songs you love, with the music you already play."
- "Sing along, no hints. Next time you’ll see every note coming."
- "OnKey can’t hear you over the music. If you’re singing, turn it down a little or use headphones for a fair score."
- "Let a song play to the end. If OnKey hears only part of it, it learns the rest the next time it plays."
- "Saving shower singers from themselves since 2026" (a joke: keep it light, adapt rather than translate literally)

## Names (keep)
| Term | Notes |
|---|---|
| OnKey | The product. Never translated, transliterated or split; no article where the language can avoid one. The tagline "sing on key" is a pun on the name: translate the meaning ("sing in tune"), keep the name. |
| Spotify, Apple Music, YouTube, Shazam | Services. Keep. "the Music app" (Apple's app on Mac) is **system**: use Apple's own name for it in that language. |
| LRCLIB | A free community lyrics database. Keep, uppercase. |
| GitHub, Discord | Keep. "Open a GitHub issue": translate "issue" as the language's GitHub UI does, or keep "issue" if GitHub isn't localized there. |
| Chrome, Safari, Brave, Edge, Firefox, Opera, Vivaldi | Browsers. Keep. |
| Mac, macOS, Windows, Linux, PC | Keep. |
| singonkey.app, hello@singonkey.app | Keep exactly. |
| ⌘⇧P, Space, Esc | Keyboard shortcuts: keep the symbols. "Space" as a key name: use the OS's name for the key in that language. |

## OnKey's own words (translate, consistently)
| Term | Meaning | Treatment |
|---|---|---|
| take | One sung attempt at a song, kept with its score. "Every song you sing becomes a take." | translate (a word for "attempt/performance/recording"); some languages keep "take" (style guide decides). Always the same word. |
| Blind take | Singing with the notes hidden, to test yourself. | translate, consistently with "take". |
| learn / learned / learning | OnKey listening to a song once and working out its melody so it can be sung. "Learned · ready to sing", "Learn it again", "partly learned", "Relearn suggested". | translate as "learn" (the app learns), not "analyse". |
| lane | The scrolling strip where the notes are drawn. | translate (track / strip / band); short. |
| notes, syllable bars | The melody, drawn as a bar per syllable. | translate. |
| pitch line | The line that shows your voice live. | translate. |
| pitch, on key, on pitch, semitone | Singing in tune. "✓ On pitch". | translate with the everyday musical words of the language, not physics terms. |
| guide | The notes shown ahead to guide you. "Fade the guide on songs you know", "Full guide". | translate. |
| score, scored, Scoring level | Points out of 100 for a take. | translate. |
| Sing, Library, History, Settings | The four tabs (top bar). | translate; one short word each. "Settings" as the OS names its settings. |
| Songs to try, starter playlist | Suggested songs for a first go. | translate. |
| Mini mode | A small lyrics bar on top of other apps. | translate ("mini" is usually understood). |
| dancer | A small animated figure who dances while you sing. | translate. |
| Echo cancel | Removing the music's sound picked up by the mic from laptop speakers. | translate as the language's usual term for acoustic echo cancellation in call apps. |
| voice range | The lowest to highest notes you sing comfortably. | translate. |

| Early | The tag on languages that are new and AI-translated. | translate. |

## System labels (system)
Use the exact text the OS shows in that language, so people can find it:
- macOS: System Settings, Privacy & Security, Microphone, Screen & System Audio Recording,
  "System Audio Recording Only", Automation, Sound, the Music app.
- Windows: Settings, "Let desktop apps access your microphone".
If you aren't sure of the exact OS label, translate plainly and keep the English in brackets only for these
labels, e.g. "Grabación de audio del sistema (System Audio Recording Only)"; reviewers replace it with the real label.
